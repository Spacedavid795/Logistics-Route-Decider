Logistics Route Decider
This candidate project problem is to design a logistics Route Decider that helps organisations plan effective delivery routes.
It will provide one reliable place to view route changes, vehicle allocations, and delivery notices. Staff propose changes, managers approve them, and the system publishes updates with visible status notifications.
